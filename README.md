 Análise de Dados Financeiros com Power BI

Mini projeto desenvolvido no Power BI com o objetivo de analisar dados financeiros e apresentar os principais indicadores de receitas, despesas e margem de lucro de forma visual e interativa.

 Objetivo

Criar um dashboard que facilite a análise dos dados financeiros, permitindo visualizar a distribuição de receitas e despesas, identificar os principais componentes e acompanhar os resultados ao longo dos anos.

📌 Indicadores analisados
Total de Receitas
Total de Despesas
Margem de Lucro
Receitas por componente
Despesas por componente
Valores por ano
Segmentação dos dados por diferentes faixas de valor
🛠️ Ferramentas utilizadas
Power BI Desktop
DAX
Power Query
Excel

 Dashboard

O dashboard apresenta:

Cards com os principais indicadores financeiros;
Análise dos principais segmentos;
Comparação entre receitas e despesas;
Gráficos de receitas e despesas por componente;
Tabela detalhada com os valores por ano e categoria.




 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos de:

Tratamento e organização de dados;
Criação de medidas utilizando DAX;
Construção de indicadores financeiros;
Criação de visualizações interativas;
Segmentação e análise de dados;
Desenvolvimento e organização de dashboards no Power BI.
